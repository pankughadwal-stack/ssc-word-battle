# SSC Word Battle

A real-time 2-player word battle:
- Same word shown to both players.
- First correct submission gets +1.
- Next word appears immediately.
- First to 30 points wins.
- Works across mobile and computer when the app is hosted online.

## Run
1. Install Node.js.
2. In this folder run `npm install`.
3. Run `npm start`.
4. Open the shown address in a browser.

For true online play between different networks, deploy this Node app to a host that supports WebSockets (for example a Node-capable cloud host). Then share the deployed URL and room code.
